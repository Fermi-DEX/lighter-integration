PoSq in one paragraph

PoSq is VDF-paced blind FIFO sequencing. Time is a chain of ticks, each ≈Δ of wall clock, produced by sequential RSA-2048 squarings — the operator cannot fake the passage of time, and every 256-tick segment seals with a Wesolowski proof that the squarings actually happened. Users submit envelopes: a 39-byte visible routing header plus a timelock-encrypted body, so the operator provably cannot see order contents before fixing their position in the queue. Every submission gets a signed answer — a receipt fixing position (t,j), a signed rejection with a reason, or a signed full-window — so "my order vanished" is impossible by construction; each signed object is slashable against an on-chain bond.

What the integration gives Lighter

Lighter proves execution in SNARKs but its sequencer still picks the transaction order unverifiably. Because Lighter's time priority is the per-side order nonce — assigned in execution order — every fairness property reduces to one equality: the batch's transaction stream equals the opened prefix of the PoSq tape. Bind that (the stream commitment you see recomputed in panel 3) and Lighter transitively inherits: fair ordering (front-running dead), cancel priority (stale-quote sniping dead), accountable admission, and on-chain fraud proofs with real slashing.

Glossary

tick
the atomic time unit: q sequential RSA squarings ≈ Δ of wall clock. Positions in a tick are (t, j).
segment
a fixed run of ticks (256 on this deployment), sealed with a Wesolowski proof that the squarings were performed — the auditable clock.
envelope
the fixed-size (1024 B) submission: 39-byte visible routing header (bucket, namespace, window, delay class, nonce) + timelock-encrypted body. All ops look identical on the wire.
receipt
the signed admission ack fixing (t, j) for commitment h, digest-chained to every prior admission. Slashable.
tape
the totally-ordered sequence of admitted positions and their outcomes: pending → opened / gap. The adapter consumes it strictly in order.
gap
a consumed position with no executable payload (undecryptable, invalid, or unopened by cutoff). Permanent, visible, attributable — never silently reused.
stream commitment
s_n = fold of keccak over opened payloads in (t, j) order. The single value that binds a Lighter batch to the tape (challenge-able on the bridge).
anchor
periodic checkpoint (segment span, log head, receipts root, segment x_end hashes) signed and posted to PoSqHost.
fraud proof
on-chain proof of reorder / omission / equivocation / invalid log / forced default → bond slashed, RescueMode, challenger bounty.
forced inclusion
forceInclude(h) on-chain → the sequencer must exhibit a receipt within F_force ticks or be slashed (proveForcedDefault).
